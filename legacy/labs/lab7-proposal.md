# lab7｜留出条件检验与可执行研究提案

[索引](../guides/course-map.md) · [对应课程 lab7](../modules/lab7-proposal.md) · [前置 lab6](lab6-reproduction.md)

> [!tip] AI 辅助增强

## 目标与默认任务

在没用来选择假设的新输入条件下，检查 lab6 的现象是否延续，然后形成下一轮两周研究计划。默认只把输入长度从 1024 改为 1536，输出仍为 64，比较 budget 512 与 2048；其他条件固定。这样检验的是长度条件改变后的规律，而非同时换模型、输出长度和框架。

这个教学留出条件不是正式论文的完整独立测试集，也不证明创新。它用于训练：先预测、再测量、最后根据新证据修正信念。

## 300 分钟执行表

| 时间 | 任务 |
|---|---|
| 0–20 | 固定留出条件、主指标、预测与失败处理 |
| 20–110 | 按 lab6 流程完成 12 次测量，核对实际长度 |
| 110–155 | 对照 lab6，分析规律是否稳定以及替代解释 |
| 155–230 | 把数据写回两页提案，完善未来两周实验 |
| 230–270 | 检查可复查性与查重边界，做 10 分钟汇报彩排 |
| 270–300 | 整理结课包、周报与向导师请教的事项 |

## 运行矩阵与降级

矩阵：2 budget×2 个原来的有限到达率×3 seed=12 次；N 沿用前两周，主指标仍为 p95 TPOT，辅助指标相同。沿用 lab6 的 A/B 交错区组、重启预热与保存规则。不要根据新长度重新为 A/B 各挑一个有利到达率。

1536＋64 在默认 2048 上下文内。如果你已因显存将上下文降至 1536，可使用输入 1408；上下文降至 1024 时，lab6 的长输入应已统一改为 768，本周可用 896。实际输入必须比上周更长且加最大输出不超过模型限制；无法满足时先明确改写验证问题，不能运行超限后把报错当作性能退化。

更长输入可能造成原 high rate 过载。记录排队、失败、持续时间；过载本身是边界证据。若需要后续降低 rate，另开一轮实验并对 A/B 一起改，不与原 rate 混在同一主对照中。时间不足先保存完成的条件，缺失项标待补，不伪造完整矩阵。

## 分析要回答的五个问题

1. lab6 的主要趋势在新条件下是否仍出现？轮间波动允许做多强的判断？
2. 若反转，反转发生在低负载、高负载还是两者？是否伴随失败/长度变化？
3. 这是否已经在相关工作中被预期或评估？能引用到哪一段，而非只看标题？
4. 当前最需要补的是新机制、真实负载、更大模型，还是更可靠的测量？
5. 下一次只增加哪一项证据，就能决定继续或放弃？

## 两页提案的具体要求

使用 [提案模板](../templates/research-proposal.md)，约 1,200–1,800 中文字，一张主图，列最接近的三项工作并直接链接。把句子分为事实、推断、假设、计划四类，检查有没有将未来计划写成已完成成果。

未来两周至少明确六个任务：核实最接近工作；验证最危险的解释；确定/实现最小 baseline；完成一组控制实验；评估额外开销或质量约束；整理继续/停止判断。每项写输入、输出、时间预算和卡点，不用“深入研究调度”这样的泛任务。

如果准备提出自适应 budget 或长度感知调度，它们已有大量相关研究，必须先查重；性能曲线发生变化只是动机，不能直接当作算法创新。暂未找到缺口时，标题写“某条件下的性能边界调查与下一步计划”，并请求导师提供更具体的开放问题。

## 结课包

你的实验仓库首页应直接连到：

1. 环境与一条运行入口，注明哪些实验需 GPU。
2. 论文地图与 6–8 篇关键部分阅读卡。
3. lab1/lab2 的正确性和测量结果。
4. lab3/lab4/lab6/lab7 的服务配置、原始数据和图。
5. lab5 的模拟与局限，明确它与真实系统实验不同。
6. 机制复现报告、两页提案、10 分钟汇报提纲与个人贡献说明。

不要把模型权重、虚拟环境或大缓存直接塞进 Git 仓库；提供模型标识、revision 与获取步骤即可。课程笔记与代码之间可以用你自己的相对路径链接。

## 最终验收

- [ ] 新条件在运行前定义，未按结果挑选主指标。
- [ ] 留出结果支持、反驳或证据不足三种情况之一被准确说明。
- [ ] 最接近的三项工作有具体重合/差异分析，“未查到”没有写成“不存在”。
- [ ] 两周计划第一项能在现有资源上开始；算力请求有具体用途。
- [ ] 10 分钟内能说明问题、证据、限制和想请教的一件事。
- [ ] 结课材料真实反映研究阶段，没有把复现包装成已完成创新论文。

通过后的下一步是带着这套材料与老师确定一项具体研究任务，再把该任务拆成下一轮课程。申请材料安排见 [到 2027 年暑期的路径](../guides/research-roadmap.md)。
