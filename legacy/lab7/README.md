# lab7：留出验证与研究提案

继续 lab6 的研究项目，在未用于调参的条件下检验结论，整理实验资料并提出下一步计划。

## 内容

- [research.md](research.md)：不同研究路线的留出实验与归档要求。
- [proposal.md](proposal.md)、[talk.md](talk.md)：研究提案与汇报提纲。
- [upstream-record.md](../templates/upstream-record.md)：上游源码与修改记录。
- [systems.md](systems.md)：系统任务的验收要求；[portfolio/](../portfolio/README.md)：课程成果索引。
- [assignment.md](assignment.md)、`plan.py`、`tests.py`：更长输入下的服务留出方法练习。
- [setup.md](setup.md)、[grade.md](grade.md)：方法练习的环境与评分。

## 使用顺序

1. 沿用 lab6 的项目，事先写下留出条件、预测与判据。
2. 执行实验，保留失败、反转与不确定的结果。
3. 检查原始数据到图表的重建过程，补齐源码与环境记录。
4. 完成提案和汇报，将实际成果加入课程索引。

留出条件不能在看过结果后重新调参。服务方法练习只适用于对应项目，其他路线按 `research.md` 选择验证条件。
