# KV 分页与引擎生命周期

实现可检查的 KV 页表与引用计数，再将分配、共享、抢占和释放映射到真实推理引擎。

主要文件：

- `allocator.py`：待完成的分配、释放、前缀共享和追加操作。
- `reference.py`：连续预留容量模型。
- `tests.py`：状态与资源守恒测试。
- `run.py`：事件执行入口。

建议顺序：

1. 阅读 [setup.md](setup.md)，准备本地测试和引擎环境。
2. 按 [assignment.md](assignment.md) 实现状态机并完成资源实验。
3. 阅读引擎源码，提交可运行的诊断修改与测试。
4. 按 [grade.md](grade.md) 自评，再选择论文拓展。

本地状态机仅需 Python 标准库，不包含 GPU KV 存储。容量模型不能用于推断真实延迟；引擎集成需要单独运行验证。
