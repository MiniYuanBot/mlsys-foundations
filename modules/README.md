# 课程模块

这里按主题提供基础讲解、阅读安排和课内练习。完整的系统任务与时间安排见 [课程计划](../syllabus.md)。

| 顺序 | 内容 |
|---|---|
| [lab0](lab0-pytorch.md) | PyTorch、张量与训练循环 |
| [lab1](lab1-measurement.md) | GPU 计时、显存与性能测量 |
| [lab2](lab2-kernels.md) | 算子融合与 GPU kernel |
| [lab3](lab3-serving.md) | 推理服务、请求指标与 KV cache |
| [lab4](lab4-scheduling.md) | 负载、批处理与调度 |
| [lab5](lab5-directions.md) | 分布式训练、RL 系统与方向选择 |
| [lab6](lab6-reproduction.md) | 复现设计与控制变量 |
| [lab7](lab7-proposal.md) | 研究提案与结果表达 |

建议按 lab0–lab7 阅读，每章配合 [基础实验题面](../labs/README.md) 和 [实验代码](../../mlsys-research-labs/README.md) 使用。已掌握的基础可通过检查后跳过，系统任务按课程计划完成。

各章 A、B 课后列有课内题，每组前两题必做、第三题选做。图示和交互演示可从 [可视化资料](../readings/visualizations.md) 查找；计算、草图与小段验证代码可直接用于实验报告。
