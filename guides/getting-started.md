# 开始学习

## 第一次使用

1. 读 [课程大纲](../syllabus.md)，了解 16 周的安排和每个 lab 要做什么。
2. 按 labs 仓库的 [setup.md](../../mlsys-research-labs/setup.md) 装好 lab0 的环境（约 30 分钟）：运行一次 `setup_env --lab 0`，再用 `check_env --lab 0` 检查。后面每开始一个 lab 再运行一次，补装那个 lab 新增的东西。
3. 打开 [L0 讲义](../lectures/L0-tensor-runtime.md)，读完 §1 后进入 [lab0](../../mlsys-research-labs/lab0/README.md) 的 Part A。

## 每周节奏

| 时间 | 做什么 |
|---|---|
| 第 1 次课（3h） | 读讲义的 1–2 节，做完节末自测题；不确定的地方在笔记里标出来 |
| 第 2 次课（3h） | 读剩下的节，并读讲义指定的论文或博客段落 |
| Lab 时间（5–7h） | 按 lab README 一步步做：写代码 → 跑测试 → 跑 benchmark → 记录数字 → 解释原因 |
| 周末（30min） | 写 [周报](../templates/weekly-report.md)：完成了什么、卡在哪里、下周计划 |

讲义和 lab 是交替推进的：每读完一节，就去做 lab 的对应部分，不要攒到最后。

## 卡住时

- **概念没看懂**：先看讲义里链接的可视化资料，再把讲义的手算例子自己算一遍。
- **测试不过**：只运行这个 TODO 对应的测试（测试名带 TODO 编号），读失败信息里的文件和行号；必要时打开 sanitizer。
- **性能达不到目标**：先确认用的是 Release 构建，再对照 README 里参考实现的数字，看是哪一步落后了。
- **环境问题超过 30 分钟**：保存最短复现命令和完整报错，写进周报；超过 90 分钟就停下来问人。

## 和导师交流

建议在第 4、8、12、16 周各准备一份 10 分钟的材料：做了什么、测到了什么、发现了什么问题、下一步想做什么。第 8 周开始，结合 [研究路线](research-roadmap.md) 思考选题。
