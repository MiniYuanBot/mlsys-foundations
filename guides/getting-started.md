# 开始学习

课程按 lab0–lab7 推进，建议用 16 周、每周约 11 小时。完整安排见 [syllabus.md](../syllabus.md)。

## 第一次使用

1. 阅读 [课程地图](course-map.md)，了解各章主题和代码位置。
2. 按 [环境指南](environment.md) 准备当前章节需要的工具。
3. 从 [lab0](../../mlsys-research-labs/lab0/README.md) 开始，检查训练、梯度和 C++ 基础。
4. 每次实验前写计划，运行后保存原始数据、命令与简短结论。

## 学习节奏

每周约 4 小时用于阅读和源码分析，7 小时用于实现、测量与报告。基础练习用于查漏补缺；系统任务通常跨两周完成。安装和调试也计入时间，遇到阻塞时记录最小复现与错误日志，再安排补做。

每章先读 [论文清单](../readings/papers.md) 指定的基础与进阶材料，其余按研究问题选读。读源码时固定实际使用的提交，记录自己的修改。使用外部课程任务前，先看 [复用说明](../readings/open-source-labs.md)。

课内题在各章 A、B 课表之后，每组先做前两题，第三题选做。先手算或画出预测，再对照 [可视化资料](../readings/visualizations.md) 和小规模运行结果，保留修正过程。题目穿插在对应课时内，草稿可复用到实验报告，无需重复提交一套作业。

## 完成要求

基础、系统、研究三类成绩分别记录。完成各章系统任务后，在 lab6 选择一个研究方向，lab7 延续同一项目完成留出验证、结果归档和提案。具体门槛见 [测试与评分](../../mlsys-research-labs/docs/grading.md)。

每章结束时，尝试独立解释一次代码修改、预测一个新条件并验证。报告按实际情况区分模拟、CPU、单卡和多卡结果；没有加速或假设不成立也应保留。

建议在第 3、7、11、16 周整理一份简短材料，向导师或同学讨论实现、系统问题、研究方向与下一步计划。后续安排见 [研究路线](research-roadmap.md)。
