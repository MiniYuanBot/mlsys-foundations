# 学习与实验指南

这里说明如何安排学习、准备环境、阅读论文和记录实验。具体任务见 [课程计划](../syllabus.md)。

建议按下面的顺序使用；后四项在需要时查阅。

1. [起步指南](getting-started.md)：确认先修知识、时间和学习目标。
2. [课程地图](course-map.md)：找到各模块、实验和资料。
3. [环境准备](environment.md)：选择平台，确认依赖与硬件。
4. [实验规范](experiments.md)：设置对照、记录测量、保存结果。
5. [论文阅读](reading.md)：提取问题、机制与证据。
6. [研究路线](research-roadmap.md)：筛选方向并安排后续工作。
7. [在线评测](online-judge.md)：选择适合当前阶段的算子练习。
8. [AI 辅助实验](ai-assisted-labs.md)：使用辅助工具扩展练习并核查结果。

环境文档提供配置步骤，实验代码和逐项检查见 [配套仓库](../../mlsys-research-labs/README.md)。
