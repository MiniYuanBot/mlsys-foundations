# 阅读资料

这里按实验主题整理论文、参考课程和可复用的开源作业。

| 文件 | 用途 |
|---|---|
| [papers.md](papers.md) | 每章的核心论文、阅读重点与研究问题 |
| [visualizations.md](visualizations.md) | 按课内题查找交互演示、机制图和性能时间线 |
| [resources.md](resources.md) | 补先修知识、查 API 和寻找课程讲义 |
| [open-source-labs.md](open-source-labs.md) | 选用上游实验，核对任务范围、硬件与许可证 |

先按当前章节读 `papers.md` 指定的部分，做课内题时选用对应的可视化资料；遇到知识缺口再查 `resources.md`。决定复用开源作业前，先读对应的适配说明。

论文和项目可能面向不同硬件。实验时记录所用代码提交、依赖和设备，不把阅读过的结果记成自己的测量。
