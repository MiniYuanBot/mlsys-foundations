# 学习与实验指南

这里说明如何安排学习、准备环境、阅读论文和记录实验。具体任务见 [课程计划](../syllabus.md)。

建议按下面的顺序使用；后四项在需要时查阅。

1. [起步指南](getting-started.md)：确认先修知识、时间和学习目标。
2. [环境准备](environment.md)：设备分工、显存限制与 HPC；安装步骤在 `labs/` 中的 setup.md。
3. [实验规范](experiments.md)：设置对照、记录测量、保存结果。
4. [论文阅读](reading.md)：提取问题、机制与证据。
5. [研究路线](research-roadmap.md)：筛选方向并安排后续工作。
6. [在线评测](online-judge.md)：选择适合当前阶段的算子练习。

安装步骤、实验代码和逐项检查都在 [配套实验](../../labs/README.md)。
