# 记录与报告模板

这里提供学习和实验过程中使用的 Markdown 模板。复制后填写，保留空白模板供后续使用。

| 模板                                             | 使用时机                             |
| ------------------------------------------------ | ------------------------------------ |
| [paper-card.md](paper-card.md)                   | 读完一篇论文，记录问题、机制与证据   |
| [experiment-record.md](experiment-record.md)     | 开始实验前写假设与配置，结束后补结果 |
| [weekly-report.md](weekly-report.md)             | 每周整理进展、疑问和下周安排         |
| [reproduction-report.md](reproduction-report.md) | 完成对照、消融与留出实验后汇总       |
| [research-proposal.md](research-proposal.md)     | 用已有证据提出下一步研究计划         |

建议先持续积累阅读卡和实验记录，再据此写复现报告与提案。记录中保留原始数据、代码提交和运行命令的位置，方便回查。
