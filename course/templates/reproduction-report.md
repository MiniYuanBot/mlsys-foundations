# 机制复现报告｜主张名称

[返回大纲](../syllabus.md)

## 1. 原论文到底主张什么

论文链接、图/表/小节；用自己的话说明主张的适用范围，写明模型、硬件、负载和指标。

## 2. 我复现的范围

| 项目           | 原论文 | 本实验 | 差异可能造成的影响 |
| -------------- | ------ | ------ | ------------------ |
| 硬件/模型/版本 | 待填   | 待填   | 待填               |
| 负载/指标/方法 | 待填   | 待填   | 待填               |

标注：原 artifact 重跑 / 机制检验 / 缩规模教学复现。不得把后两者写成复现原文全部加速比。

## 3. 预注册假设和实验

自变量、控制变量、baseline、重复、seed、原始日志位置。附完整命令的链接。

## 4. 结果

一张主图、一张运行汇总表、一张失败或不符合预期的图。无失败图时写“未观察到”，不要编造。

## 5. 解释与局限

观察事实、支持的机制、尚存替代解释、最小反例、下一步验证。

## 6. 可复查性

从环境文件开始，另一位同学需要执行哪些命令才能重建主图？哪些文件无法公开，为什么？
