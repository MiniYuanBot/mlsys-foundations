# 讲义

每讲对应两周，与同编号的 lab 配套。讲义分成若干节，每节 45–60 分钟；每读完一节就去做 lab 的对应部分。

每讲的结构相同：

1. **要解决的问题**：开头列出 2–3 个问题
2. **从基础推导**：先讲原理，配图示和手算例子
3. **对应 lab**：每节末尾说明该去做 lab 的哪一部分
4. **自测题**：答案默认折叠，先自己想
5. **演进脉络**：从奠基工作到 2025–26 年的前沿，每一步解决了上一步的什么问题
6. **研究问题种子**：可以作为后续选题的起点
7. **可视化资料汇总**
