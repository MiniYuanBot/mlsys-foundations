# 命令工具

从实验仓库根目录运行，具体参数可用 `python -m tools.<工具名> --help` 查看。

| 工具 | 用途 |
|---|---|
| `doctor.py` | 检查解释器和实验依赖 |
| `capture.py` | 保存外部命令、配置与运行日志 |
| `run_tests.py` | 运行指定测试并输出记录 |
| `grade.py` | 根据测试和人工证据生成自评结果 |
| `plot.py` | 从 CSV 数据生成图表 |

先检查环境，再按各 lab 运行实验，最后整理数据与评分。评分用法见 [grading.md](../docs/grading.md)；这些工具不会安装依赖，人工评分仍需自行核对证据。
