# 实验记录模板

复制后填写。

| 文件                                     | 用途                                               |
| ---------------------------------------- | -------------------------------------------------- |
| [report.md](report.md)                   | 每个 lab 的报告，复制到 `reports/labN.md`          |
| [preregister.md](preregister.md)         | 研究型实验开始前，登记假设、指标和对照             |
| [upstream-record.md](upstream-record.md) | 使用或修改外部代码时，记录来源、版本、许可证和改动 |
| [weekly-report.md](weekly-report.md)     | 每周整理进度、结果和问题                           |
| [oj-record.md](oj-record.md)             | 在线评测（LeetGPU、GPU MODE 等）的条件与提交记录   |
