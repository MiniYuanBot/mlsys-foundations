# 实验记录模板

复制模板后填写自己的计划与记录。

| 文件 | 用途 |
|---|---|
| [preregister.md](preregister.md) | 实验前登记假设、指标和对照 |
| [upstream-record.md](upstream-record.md) | 记录外部代码、许可证和改动 |
| [weekly-report.md](weekly-report.md) | 整理进度、结果和问题 |
| [oj-record.md](oj-record.md) | 记录在线评测条件与提交结果 |

先写实验计划；使用外部代码时补来源记录；运行后把原始数据和报告链接填入周报。模板本身不是完成实验的证据。
