# 基础实验题面

这里保存基础实验的目标、步骤和提交要求。实现框架、测试、系统任务与评分在 [mlsys-research-labs](../../mlsys-research-labs/README.md)。

| 顺序 | 实验 |

本目录只覆盖基础练习；各章还需完成 [课程计划](../syllabus.md) 中对应的系统任务。模拟结果应注明假设，实际性能结论须来自真实运行。
